# AWG Rule-Set Helper

Небольшое расширение для Google Chrome и Firefox, которое управляет rule-set'ами [AWG Manager](https://github.com/hoaxisr/awg-manager) через его HTTP API: добавляет домены в наборы, редактирует содержимое и проверяет соединение — без захода в веб-интерфейс.

## Возможности

- **Быстрое добавление домена** в выбранный inline-rule-set одной кнопкой (или Enter в поле ввода).
- **Автоподстановка домена активной вкладки** в поле «Домен или URL».
- **Отдельная страница-редактор** содержимого выбранного набора (Pretty JSON, Ctrl/Cmd+S для сохранения).
- **Проверка соединения** (GET `/rulesets/list`) с выводом результата рядом с кнопкой.
- **Контекстное меню**: ПКМ по странице или ссылке → «Добавить домен … в rule-set AWG».
- **История** добавленных доменов.
- Тёмная/светлая тема — автоматически следует за настройками браузера.

## Установка

1. Скачайте последний релиз со страницы **GitHub Releases** (например `awg-ruleset-helper-v1.0.0.zip`) и распакуйте архив

### Google Chrome

1. Откройте `chrome://extensions`
2. Включите **Режим разработчика** (Developer mode, справа сверху)
3. Нажмите **"Загрузить распакованное"** (Load unpacked) и выберите распакованную папку с `manifest.json`

### Firefox

1. Откройте `about:debugging#/runtime/this-firefox`
2. Нажмите **"Загрузить временное дополнение"** (Load Temporary Add-on)
3. Выберите файл `manifest.json` в распакованной папке

Временное дополнение Firefox удаляется после перезапуска браузера.

## Быстрый старт

1. Нажмите на иконку расширения в панели инструментов.
2. В блоке «Настройки» укажите:
   - **Base URL (API)** — например `http://192.168.1.1:2222/api`;
   - **API Key** — если в AWG Manager включена авторизация (Берется из: Настройки → Расширенные → «API Key»);
   - **Раздел API** — `FakeIP config` или `Router` в зависимости от того, где создан ваш набор;
   - **Тег rule-set** — выберите нужный inline-набор из списка (кнопка «Обновить список»).
3. Нажмите **«Проверить»** — при успехе покажет количество найденных наборов.
4. Нажмите **«Сохранить»**, чтобы запомнить настройки.

### Добавление домена

Введите домен или URL (например `rutracker.org` или `https://tracker.site`) и нажмите «Добавить в rule-set». Домен будет добавлен в выбранный набор (по умолчанию `domain_suffix` — вместе со всеми поддоменами; точный матч включается настройкой «Матчинг» → `domain`).

Домен активной вкладки подставляется автоматически при открытии попапа.

### Контекстное меню

ПКМ по любой странице или ссылке → «Добавить домен … в rule-set AWG». Результат придёт системным уведомлением.

### Редактор содержимого

Кнопка **«Редактор»** в шапке попапа открывает отдельную вкладку:

- выберите набор и нажмите «Загрузить содержимое»;
- отредактируйте JSON-массив правил `rules`;
- «Сохранить содержимое» валидирует JSON и сохраняет через `/update`; после сохранения содержимое перезагружается с сервера;
- `Ctrl/Cmd+S` — быстрый способ сохранить.

## Настройки

| Параметр              | Описание                                                                 |
| --------------------- | ------------------------------------------------------------------------ |
| `Base URL (API)`      | Адрес API AWG Manager, например `http://192.168.1.1:2222/api`.           |
| `API Key`             | Bearer-токен из Настроек AWG Manager (если включена авторизация).        |
| `Раздел API`          | `singbox/fakeip/config/rulesets/*` или `singbox/router/rulesets/*`.      |
| `Тег rule-set`        | Тег inline-набора; список грузится из API (кнопка «Обновить список»).    |
| `Матчинг`             | `domain_suffix` (домен + поддомены) или `domain` (только точный домен).  |

Все значения хранятся локально в `chrome.storage.local` и никуда не отправляются, кроме указанного Base URL в качестве API-запроса.

## Упрощение host_permissions

По умолчанию в `manifest.json` открыт доступ ко всем адресам. Для безопасности можно ограничить:

```json
"host_permissions": ["http://192.168.1.1:2222/*"]
```

(замените на адрес вашего роутера/AWG Manager).

## Права расширения

- `storage` — хранение настроек и истории;
- `tabs` — чтение URL активной вкладки для автозаполнения домена;
- `contextMenus` — пункты контекстного меню;
- `notifications` — уведомления о результате из контекстного меню.

## Примечания и ограничения

- Расширение **заменяет содержимое набора целиком** при сохранении (так устроен API `/update`), поэтому перед добавлением домена оно сначала читает текущий список правил.
- В rule-set'ах sing-box (включая inline) нельзя использовать matcher `protocol` — его поддерживают только `route.rules`/`dns.rules`. Для таких правил используйте слот конфигурации `90-user.json` в самом AWG Manager.
- Если расширение перестало работать — проверьте, не изменился ли формат API AWG Manager, и порог авторизации (401/403 при неверном ключе).

## Совместимость

- Manifest V3, Google Chrome 121+, браузеры Chromium 121+ и Firefox 121+. В Chrome используется `background.service_worker`, а в Firefox — `background.scripts`. Расширение не использует серверные компоненты и работает полностью локально.
- Единый manifest с `background.scripts` поддерживается в Chrome и Firefox начиная с версии 121.
- API AWG Manager: эндпоинты `GET /singbox/{fakeip/config|router}/rulesets/list` и `POST /singbox/{fakeip/config|router}/rulesets/update`.
